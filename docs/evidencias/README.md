# Evidencias de entrega

Esta carpeta es una guía para evidencias futuras; todavía no contiene capturas.

- Añade evidencias solo cuando la función exista y se haya ejecutado.
- Usa cuentas y datos de prueba o anonimiza toda información personal.
- No guardes contraseñas, tokens, archivos de servicio ni capturas sensibles en el repositorio. La subcarpeta `privadas/` está excluida por `.gitignore`.
- Acompaña cada captura con una nota breve del escenario y del resultado observado. Distingue las pruebas locales de cualquier verificación en dispositivo real.
